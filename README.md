# Páginas Errantes · Librería online

Tienda de libros con portadas 3D animadas, filtros, búsqueda, carrito y vista rápida.
HTML + CSS + JavaScript puro, sin dependencias.

## Publicar en GitHub Pages
1. Sube la carpeta a un repositorio.
2. Settings → Pages → Branch `main` / carpeta `/root`.
3. Abre la URL que te da GitHub.

## Personalizar
Edita el arreglo `BOOKS` en `js/app.js` (título, autor, precio, colores de portada).
